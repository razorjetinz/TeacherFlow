# Contributing

Thank you for helping improve TeacherFlow.

## Project principles

- Keep the core application static and usable without API keys.
- Do not upload teacher materials or lesson content to an application server.
- Make third-party AI integrations optional and clearly explain any costs or privacy implications.
- Keep teaching outputs age-appropriate, inclusive, and easy to follow in a classroom.
- Be transparent about limitations and about any AI-generated or unverified content.

## Suggestions and bug reports

Open a GitHub issue with:
- A clear description of the issue or proposed improvement.
- Steps to reproduce, where relevant.
- Browser and operating system details for bugs.
- Screenshots only after removing learner-identifying information.

## Changes

For pull requests, explain the user-visible change and test the lesson creation, AI handoff, save/reopen, guided teaching and export workflows.
