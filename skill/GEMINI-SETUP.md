# Using TeacherFlow with Gemini

1. Prepare a lesson brief in TeacherFlow.
2. Open [SKILL.md](SKILL.md) and use the file with Gemini's Skills feature if it is enabled for your account.
3. Follow Google's current Skills upload instructions. If the interface requests an archive, create a ZIP containing `SKILL.md` at the archive root.
4. Attach the original lesson material in Gemini and paste the lesson brief.
5. Review the generated lesson and copy it back into TeacherFlow.

Feature availability and eligibility can vary. If Skills are unavailable, paste [QUICK-START-PROMPT.md](QUICK-START-PROMPT.md) into a regular chat.

Official guide: https://support.google.com/gemini/answer/17094296
