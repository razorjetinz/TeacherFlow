# Using TeacherFlow with Claude

1. Open the TeacherFlow app and prepare a lesson brief.
2. Download or open `SKILL.md` from this folder.
3. If your Claude account exposes the Skills upload feature, follow Anthropic's current official instructions to create or upload a skill. Package the skill directory as a ZIP if the interface requests a ZIP.
4. In Claude, attach the original lesson PDF, document, images, slides or media that you want it to analyse.
5. Paste the lesson brief and ask Claude to follow the TeacherFlow teaching skill.
6. Copy the completed lesson back into TeacherFlow's Guided Teaching workspace.

Skill availability and upload requirements can vary by plan, region and feature settings. When Skills are unavailable, paste [QUICK-START-PROMPT.md](QUICK-START-PROMPT.md) into a normal Claude chat.

Official guide: https://support.claude.com/en/articles/12512180-use-skills-in-claude
